访问当前页面的标题和路径，并在它们变化时触发事件。

## 签名

```ts
function useScriptEventPage(onChange?: (payload: TrackedPage) => void): Ref<TrackedPage> {}
```

其中 `TrackedPage` 为 `{ title?: string, path: string }`。

#### 参数

- `onChange` (可选) - 当页面标题或路径变化时 Nuxt 调用的函数。接收单个 `TrackedPage` 对象。

#### 返回值

一个包含当前页面标题和路径的 ref。

## 示例

- 跟踪页面变化。

```vue
<script setup lang="ts">
useScriptEventPage((ctx) => {
  console.log(ctx.title, ctx.path)
})
</script>
```
