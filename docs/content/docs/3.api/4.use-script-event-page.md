跟踪当前页面标题和完整路由路径，并可选择性地执行客户端回调。

## 签名

```ts
function useScriptEventPage(onChange?: (payload: TrackedPage) => void): Ref<TrackedPage> {}
```

`TrackedPage` 是 `{ title?: string, path: string }`。

## 参数

- `onChange`（可选）：当标题或路径与上一次发出的值不同时，在 `page:finish` 钩子之后于浏览器中调用。在 SSR 期间不会调用。

如果你在初始的 `page:finish` 钩子之前注册该组合式函数（通常是在 `app.vue` 中注册），则回调会接收到首次水合的页面以及后续导航。若在该钩子之后创建组合式函数，则会等待下一次页面完成；不会为之前的页面补发回调。

## 返回值

一个包含当前页面标题和完整路径的 ref，包括其查询字符串和哈希。在 SSR 期间，`title` 初始为空字符串，因为文档尚未渲染。

## 示例

记录每次页面变更：

```vue
<script setup lang="ts">
useScriptEventPage((ctx) => {
  console.log(ctx.title, ctx.path)
})
</script>
```
