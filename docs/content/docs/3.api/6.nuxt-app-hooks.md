## `scripts:updated`{lang="ts"}

- 类型：`(ctx: { scripts: Record<string, NuxtDevToolsScriptInstance> }) => void | Promise<void>`{lang="ts"}

在 Nuxt 更新脚本状态后触发。

Nuxt 内部用于开发工具，但你也可以根据需要使用它。

```ts [plugins/nuxt-scripts.ts]
export default defineNuxtPlugin({
  setup() {
    useNuxtApp().hooks.hook('scripts:updated', (ctx) => {
      console.log('Scripts updated', ctx.scripts)
    })
  }
})
```

## `scripts:globals`{lang="ts"}

- 类型：`(globals: Record<string, Record<string, any>>) => void | Promise<void>`{lang="ts"}

在生成的 `scripts:init` 插件内部触发，发生在它注册每个 `scripts.globals` 条目之前。`globals` 是一个可变的静态声明全局变量映射，以每个全局变量的 key 为键，值已经完成合并（先是构建时默认值，然后是任何 `NUXT_PUBLIC_SCRIPTS_GLOBALS_*` 环境变量覆盖）。你可以修改它来重写 `src`/属性，或者 `delete` 某个条目，这样它就永远不会加载；这些操作都可按实例进行，无需重新构建。

这相当于运行时版本的 globals 工厂：它让静态声明的全局变量在 `$scripts` 上保持类型安全并进行资源打包，同时允许你在服务端/客户端启动时计算它们的输入。删除某个条目（或设置 `enabled: false` / 空的 `src`）会跳过其注册；此后该键在 `$scripts` 上会解析为 `undefined`，因此访问时要做好保护。这个钩子只作用于已声明的集合；如果要加载一个未在 `scripts.globals` 中声明的脚本，请在你自己的插件中调用 [`useScript()`{lang="ts"}](/docs/api/use-script)。

请从一个 `enforce: 'pre'` 插件中注册该监听器，这样它会在 `scripts:init` 之前运行，否则就会来得太晚而无法触发。

```ts [plugins/nuxt-scripts-globals.ts]
export default defineNuxtPlugin({
  enforce: 'pre',
  setup(nuxtApp) {
    const { tenant } = useRuntimeConfig().public
    nuxtApp.hooks.hook('scripts:globals', (globals) => {
      // 删除这个租户未使用的集成：
      if (!tenant.awinEnabled)
        delete globals.awin
      // 从运行时配置中计算 src：
      globals.trustedShops.src = `https://widgets.trustedshops.com/${tenant.trustedShopsId}.js`
    })
  }
})
```

## `script:instance-fn`{lang="ts"} (Unhead Hook)

- 类型：`(ctx: { script: ScriptInstance<any>, fn: string | symbol, args: any, exists: boolean }) => HookResult`

这是一个 **Unhead head 钩子**（不是 Nuxt 应用钩子）。当通过代理实例访问属性时会触发它，并可通过 `injectHead().hooks.hook(...)`{lang="ts"} 访问。

Nuxt 也在内部用于开发工具，但你可以根据需要使用它。

```ts
export default defineNuxtPlugin({
  setup() {
    const head = injectHead()
    head.hooks.hook('script:instance-fn', ({ fn, args }) => {
      console.log('Function called:', fn)
    })
    const { proxy } = useScript()
    proxy.doSomething() // 函数被调用：doSomething
  }
})
```
