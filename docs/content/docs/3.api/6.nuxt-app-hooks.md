title: Nuxt 应用钩子
description: 使用 Nuxt 应用钩子来扩展 Nuxt Scripts 的运行时行为。
---

## `scripts:updated`{lang="ts"}

- 类型：`(ctx: { scripts: Record<string, NuxtDevToolsScriptInstance> }) => void | Promise<void>`{lang="ts"}

在 Nuxt 更新脚本状态后触发。

Nuxt 内部用于开发工具，但你也可以根据需要使用它。

```ts [plugins/nuxt-scripts.ts]
export default defineNuxtPlugin({
  setup() {
    useNuxtApp().hooks.hook('scripts:updated', (ctx) => {
      console.log('Scripts updated', ctx.scripts)
    })
  }
})
```

## `script:instance-fn`{lang="ts"} (Unhead 钩子)

- 类型：`(ctx: { script: ScriptInstance<any>, fn: string | symbol, args: any, exists: boolean }) => HookResult`

这是一个 **Unhead head 钩子**（不是 Nuxt 应用钩子）。当通过代理实例访问属性时会触发它，并通过 `injectHead().hooks.hook(...)`{lang="ts"} 访问。

Nuxt 也在内部用于开发工具，但你可以根据需要使用它。

```ts
export default defineNuxtPlugin({
  setup() {
    const head = injectHead()
    head.hooks.hook('script:instance-fn', ({ fn, args }) => {
      console.log('Function called:', fn)
    })
    const { proxy } = useScript()
    proxy.doSomething() // 函数被调用：doSomething
  }
})
```
