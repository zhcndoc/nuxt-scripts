在针对 [Nuxt Scripts](https://github.com/nuxt/scripts) 提交问题时，请附上最小复现案例。

## 创建复现项目

复现项目可以将模块问题与应用程序的其他部分分离开来。Nuxt 的[错误报告指南](https://nuxt.com/docs/4.x/community/reporting-bugs#create-a-minimal-reproduction)介绍了如何隔离问题并移除无关代码。

请从下面的 [StackBlitz](https://stackblitz.com) 在线 playground 开始。你可以先在那里测试模块，然后再精简项目以提交问题。
