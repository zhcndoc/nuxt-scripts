## 快速开始

Nuxt Scripts 2 需要 [Node.js](https://nodejs.org) 24 或更高版本、Nuxt 4.5.1 或
更高版本（包括 Nuxt 5），以及 `Unhead >=3.3.1 <4`。在安装前升级现有项目：

```bash
npx nuxi@latest upgrade --force
```

运行：

```bash
npx nuxi@latest module add scripts
```

> [!TIP]
> 使用 [skilld](https://github.com/skilld-dev/skilld) 为此软件包生成代理技能：
> ```bash
> npx skilld add @nuxt/scripts
> ```

[Nuxt 模块命令](https://nuxt.com/docs/api/commands/module) 会安装 Nuxt Scripts，并将其添加到 Nuxt 配置中的 `modules` 数组。
