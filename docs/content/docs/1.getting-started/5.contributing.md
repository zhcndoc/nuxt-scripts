## 准备环境

`@nuxt/scripts` 是一个 [pnpm](https://pnpm.io) 工作区。使用 pnpm 安装并链接其依赖项。

克隆仓库后，运行：

```sh
pnpm i && pnpm dev:prepare
```

## 运行 playground

使用以下命令启动 playground 开发服务器：

```sh
pnpm dev
```

## 检查你的更改

提交更改之前，运行仓库的 lint 和测试命令：

```sh
pnpm lint
pnpm test:run
```
