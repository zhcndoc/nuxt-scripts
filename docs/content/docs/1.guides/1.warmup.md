---
title: 预热策略
description: 自定义脚本所使用的预加载或预连接策略。
---

例如，如果我们有如下脚本：

```ts
useScript('/script.js')
```

这段代码将在 `onNuxtReady` 事件触发时加载 `/script.js`。由于 Nuxt 应用在水合期间网络可能处于空闲状态，Nuxt Scripts 会利用这段时间，在文档头部插入 `preload` 标签来预热脚本。

```html
<link rel="preload" href="/script.js" as="script" fetchpriority="low">
```

该行为仅在使用 `client` 或 `onNuxtReady` [脚本触发器](/docs/guides/script-triggers) 时生效。如需进一步自定义此行为，可以使用 `warmupStrategy` 选项。

## `warmupStrategy`

`warmupStrategy` 选项可用于自定义插入文档的 `link` 标签。该选项可以是一个函数，返回以下值之一：

*  - `false` - 禁用预热。
*  - `'preload'` - 预加载脚本，适用于需要立即加载脚本的场景。
*  - `'preconnect'` 或 `'dns-prefetch'` - 预连接到脚本来源，适用于您确定脚本将在 10 秒内加载的场景。仅在从不同来源加载脚本时有效，同来源时将回退为 `false`。

所有这些选项也可以作为回调函数的参数传入，这在脚本触发条件动态变化时非常有用。

## `warmup`

您可以显式调用 `warmup` 函数，为脚本添加预连接或预加载的 `link` 标签。此操作仅在函数首次调用时生效。

当您确定脚本即将被加载时，此功能非常有用。

```ts
const script = useScript('/video.js', {
  trigger: 'manual'
})
// 当我们认为用户可能需要该脚本时，预热脚本
onVisible(videoContainer, () => {
  script.warmup('preload')
})
// 加载脚本
onClick(videoContainer, () => {
  script.load()
})
```
