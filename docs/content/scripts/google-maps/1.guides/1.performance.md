title: 性能
---

`ScriptGoogleMaps` 默认已优化：JavaScript API 仅在用户与地图交互时才会加载。在此之前，会显示一个轻量级的静态图片占位图。

## 加载策略

### 默认：懒加载（推荐）

默认情况下，地图在 `mouseenter`、`mouseover` 或 `mousedown` 时加载。大多数页面访问者不会与地图交互，因此你可以为这些会话避免支付 Maps JavaScript API 费用。

```vue
<template>
  <!-- 在首次悬停/点击时加载 JS API -->
  <ScriptGoogleMaps
    :center="{ lat: -33.8688, lng: 151.2093 }"
    :zoom="12"
  />
</template>
```

### 立即加载

强制 JavaScript API 随页面一起加载。仅在地图是主要内容且需要从一开始就具有交互性时使用此选项。

```vue
<template>
  <ScriptGoogleMaps
    trigger="immediate"
    :center="{ lat: -33.8688, lng: 151.2093 }"
    :zoom="12"
  />
</template>
```

::callout{color="amber"}
立即加载会在每次页面浏览时收取 Maps JavaScript API 费用（$7/1000 次）。仅当地图对页面体验至关重要时才使用此选项。
::

### 自定义触发器

你可以使用任何[元素事件触发器](/docs/guides/script-triggers#element-event-triggers)来精确控制地图何时加载。

```vue
<template>
  <!-- 仅在明确点击时加载 -->
  <ScriptGoogleMaps trigger="mousedown" />

  <!-- 当元素进入视口时加载 -->
  <ScriptGoogleMaps trigger="visible" />
</template>
```

## 占位图优化

### 首屏

当地图无需滚动即可见时，将其标记为优先加载。这会将占位图设置为 `loading="eager"` 并添加 `preconnect` 提示。

```vue
<template>
  <ScriptGoogleMaps above-the-fold />
</template>
```

### 自定义占位图

用你自己的图片替换默认的 Google 静态地图图片，以避免产生静态地图 API 费用。用法请参见 [`#placeholder` 插槽](/scripts/google-maps/api/script-google-maps#slots)。

## 标记点性能

当渲染大量标记点时，使用[标记点聚类](/scripts/google-maps/guides/marker-clustering)来将附近的标记点分组。这可以显著减少 DOM 元素数量并提升平移/缩放性能。

有关完整的费用明细和优化策略，请参阅[计费与权限](/scripts/google-maps/guides/billing)。
