## 必需的 API 权限

仅启用实现所使用的 API：

| API | 必需？ | 使用时机 |
|---|---|---|
| [Maps JavaScript API](https://developers.google.com/maps/documentation/javascript/get-api-key) | 是 | 交互式地图渲染 |
| [Maps Static API](https://developers.google.com/maps/documentation/maps-static/get-api-key) | 可选 | `<ScriptGoogleMapsStaticMap>`{lang="html"} 图像，包括放置在 `#placeholder` 插槽中的图像 |
| [Places API (Legacy)](https://developers.google.com/maps/documentation/javascript/legacy/places) | 可选 | 通过 `resolveQueryToLatLng()`{lang="ts"} 解析地址 |

默认情况下，占位符插槽为空，因此普通的 `<ScriptGoogleMaps>`{lang="html"} 不会调用 Maps Static API。

## 当前定价

Google 按 SKU 对每个 API 收费，并为每个 SKU 分别设置每月免费使用额度。截至 2026 年 7 月，相关的全球标价如下：

| 操作 | SKU | 每月免费事件数 | 每 1,000 次的首个付费层级 | 计费时机 |
|---|---|---:|---:|---|
| 加载交互式地图 | Dynamic Maps | 10,000 | $7 | 每次 Maps JavaScript API 创建地图时 |
| 加载静态预览 | Static Maps | 10,000 | $2 | 每次 `<ScriptGoogleMapsStaticMap>`{lang="html"} 图片请求时 |
| 在浏览器中解析地址 | Find Place (legacy) | 5,000 | $17 | 每次 `resolveQueryToLatLng()`{lang="ts"} 查询时 |

以上是第一个付费量级的美元标价。更高用量的层级、区域定价和产品变更可能会影响总费用；在制定预算前，请查看[当前 Google Maps Platform 价格表](https://developers.google.com/maps/billing-and-pricing/pricing)。

Google 还提供[固定价格订阅方案](https://developers.google.com/maps/billing-and-pricing/subscriptions)，在所包含的 SKU 之间共享每月调用额度。超出额度的调用将恢复按量付费，因此下面的估算使用标准标价。

Google 于 2025 年 3 月 1 日以按 SKU 计算的免费使用额度取代了原有的每月 200 美元循环抵扣额度。[Google 的定价概览](https://developers.google.com/maps/billing-and-pricing/overview)介绍了当前的计费模式。

## Nuxt Scripts 如何影响使用方式

**延迟加载：** Dynamic Maps 事件仅在配置的触发器触发后才会发生。使用默认的交互触发器时，从未与地图交互的访客不会加载 JavaScript API。

**不发起默认静态请求：** `<ScriptGoogleMaps>`{lang="html"} 的占位符为空。仅当地图预览值得额外的 Static Maps 事件时，才添加 `<ScriptGoogleMapsStaticMap>`{lang="html"}。

**地址解析：** `resolveQueryToLatLng()`{lang="ts"} 使用浏览器的 Places 库。坐标可以避免此查找过程。

**直接使用静态地图：** `<ScriptGoogleMapsStaticMap>`{lang="html"} 使用公开的浏览器密钥直接从 Google 加载图像。请为其提供一个单独的密钥，将其限制为你的网站和 Maps Static API；或者允许共享注册表密钥访问 Maps JavaScript API、Places API (Legacy) 和 Maps Static API。

## 成本控制

1. **如果有坐标，请使用坐标。** 将 `center` 传入为 `{ lat, lng }`，而不是通过 Places 解析地址。

2. **保留默认的延迟触发方式。** 仅当地图应在 hydration 后开始加载，而不是等待元素交互时，才使用 `trigger="immediate"`。

3. **使用自定义占位内容。** `#placeholder` 插槽中的本地图片不会增加任何 Maps Static API 事件。

    ```vue
    <ScriptGoogleMaps>
      <template #placeholder>
        <img src="/my-map-placeholder.webp" alt="商店位置地图">
      </template>
    </ScriptGoogleMaps>
    ```

4. **设置预算和配额限制。** Google 建议设置预算提醒以了解费用情况，并在需要严格限制用量时设置配额限制。请参阅[管理 Google Maps Platform 费用](https://developers.google.com/maps/billing-and-pricing/manage-costs)。

5. **如果需要更简单的地图，可以考虑 Embed API。** [Maps Embed API 可无限免费使用](https://developers.google.com/maps/documentation/embed/usage-and-billing)，但仍需要 API 密钥。请使用 iframe 嵌入；它不是通过 `useScript()`{lang="ts"} 加载的脚本。

## 每月估算示例

在 2026 年 7 月全球目录价格下，每月 100,000 次页面浏览量：

| 场景 | 预计每月费用 |
|---|---:|
| 无交互的延迟加载地图 | $0 |
| 20% 的访客加载交互式地图 | $70 |
| 每位访客都加载交互式地图 | $630 |
| 每次查看都显示静态预览，无交互 | $180 |
| 每次查看都显示静态预览，且 20% 的访客进行交互 | $250 |

这些示例已应用每个 SKU 的免费使用额度，但不包括 Places 请求、税费、协商折扣，以及同一结算账号下其他项目产生的费用。
