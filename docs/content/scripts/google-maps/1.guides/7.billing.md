## 必需的 API 权限

您的 Google Cloud 项目需要启用以下 API：

| API | 必需？ | 使用时机 |
|---|---|---|
| [Maps JavaScript API](https://developers.google.com/maps/documentation/javascript/cloud-setup) | 是 | 交互式地图渲染 |
| [Static Maps API](https://developers.google.com/maps/documentation/maps-static/cloud-setup) | 推荐 | JS 加载前的占位图片（除非您提供了 `#placeholder` 插槽） |
| [Geocoding API](https://developers.google.com/maps/documentation/geocoding/cloud-setup) | 可选 | 用于查询字符串的服务端地理编码代理（例如 `center="Brooklyn Bridge, NY"`） |
| [Places API](https://developers.google.com/maps/documentation/places/web-service/cloud-setup) | 可选 | 当地理编码代理不可用且使用查询字符串时的客户端回退方案 |

## 费用明细

Google Maps 采用按使用付费模式。以下是每次交互的费用：

| 操作 | 计费 API | 每 1,000 次费用 | 触发时机 |
|---|---|---|---|
| 页面加载带地图占位图 | Static Maps API | $2 | 每次页面浏览（除非 `#placeholder` 插槽覆盖） |
| 用户与地图交互（悬停/点击） | Maps JavaScript API | $7 | 仅在用户触发地图加载时 |
| 服务端解析位置查询 | Geocoding API | $5 | 仅在使用字符串查询如 `"Sydney, Australia"` 时 |
| 客户端解析位置查询 | Places API | $17 | 当未启用地理编码代理时的回退方案 |

### Nuxt Scripts 如何降低费用

Nuxt Scripts 旨在降低 Google Maps 的计费成本：

**懒加载**：JavaScript API（$7/1000）仅在用户与地图交互时加载。如果用户从未悬停或点击，您只需支付静态占位图费用（$2/1000）。

**地理编码代理**：当您在注册表中启用 `googleMaps: true` 时，服务器通过 Geocoding API（$5/1000）而非客户端 Places API（$17/1000）来解析位置查询。这使得查询解析成本降低了 70%。

**静态地图代理**：占位图通过您的服务器路由，从而启用缓存。重复访问同一页面时将提供缓存图片，而不是再次调用 Google 的 API。

### 费用优化建议

1. **使用坐标而非查询**：将 `center` 传递为 `{ lat, lng }` 而非 `"Sydney, Australia"`，以完全避免地理编码费用。

2. **提供 `#placeholder` 插槽**：用您自己的占位图替换静态地图图片，以消除 Static Maps API 的费用。

    ```vue
    <ScriptGoogleMaps>
      <template #placeholder>
        <img src="/my-map-placeholder.webp" alt="地图">
      </template>
    </ScriptGoogleMaps>
    ```

3. **仅在需要时使用 `trigger="immediate"`**：默认触发器（mouseover/mousedown）意味着大多数页面浏览不会加载 JS API。设置 `trigger="immediate"` 将在每次页面浏览时收取 $7/1000 的费用。

4. **对于非交互式地图，考虑使用 Iframe 嵌入**：如果您不需要完整的交互功能，[Google Maps Embed API](https://developers.google.com/maps/documentation/embed/get-started) 是免费的，您可以使用 `useScript()`{lang="ts"} 加载它。

## 月度费用估算

假设每月 100,000 次页面浏览：

| 场景 | 月度费用 |
|---|---|
| 仅静态占位图（无交互） | ~$200 |
| 20% 的访问者与地图交互 | ~$340 |
| 所有访问者都与地图交互 | ~$900 |
| 自定义 `#placeholder` 插槽，20% 交互 | ~$140 |

这些估算假设您拥有 Google 的[$200/月免费额度](https://mapsplatform.google.com/pricing/)。大多数中小型网站都在免费额度范围内。
