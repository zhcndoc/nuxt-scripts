::callout{color="amber" icon="i-heroicons-exclamation-triangle"}
`google.maps.Marker` 自 v3.56 起已被 Google [弃用](https://developers.google.com/maps/deprecations#google-maps-marker)。[`<ScriptGoogleMapsAdvancedMarkerElement>`{lang="html"}](/scripts/google-maps/api/advanced-marker-element) 以更出色的性能、可访问性和自定义功能取代了它。`google.maps.Marker` 目前尚未计划停用，但仅会针对重大回归问题进行错误修复。在停止支持之前，将至少提前 12 个月发出通知。
::

支持图标的经典地图标记。放置在 [`<ScriptGoogleMaps>`{lang="html"}](/scripts/google-maps/api/script-google-maps) 组件内部。

::script-types{script-key="google-maps" filter="ScriptGoogleMapsMarker"}
::

## 用法

```vue
<template>
  <ScriptGoogleMaps api-key="your-api-key">
    <ScriptGoogleMapsMarker
      :position="{ lat: -34.397, lng: 150.644 }"
    />
  </ScriptGoogleMaps>
</template>
```

### 带信息窗口

```vue
<template>
  <ScriptGoogleMaps api-key="your-api-key">
    <ScriptGoogleMapsMarker
      :position="{ lat: -34.397, lng: 150.644 }"
    >
      <ScriptGoogleMapsInfoWindow>
        <div>
          <h3>悉尼，澳大利亚</h3>
          <p>一座很棒的城市！</p>
        </div>
      </ScriptGoogleMapsInfoWindow>
    </ScriptGoogleMapsMarker>
  </ScriptGoogleMaps>
</template>
```
