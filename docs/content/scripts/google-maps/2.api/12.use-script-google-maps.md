---
title: useScriptGoogleMaps()
---

[`useScriptGoogleMaps()`{lang="ts"}](/scripts/google-maps/api/use-script-google-maps){lang="ts"} 组合式函数让您能够对 Google Maps SDK 进行细粒度的控制。它提供了一种加载 Google Maps SDK 并以编程方式与其交互的方法。

```ts
export function useScriptGoogleMaps<T extends GoogleMapsApi>(_options?: GoogleMapsInput) {}
```

请遵循 [Registry Scripts](/docs/guides/registry-scripts) 指南以了解更多高级用法。

## 选项

| 选项 | 类型 | 默认值 | 描述 |
|--------|------|---------|-------------|
| `apiKey` | `string` | - | 您的 Google Maps API 密钥（必填）。 |
| `libraries` | `string[]` | `['places']` | 要加载的 Google Maps 库。 |
| `language` | `string` | - | 控件和标签的语言（例如 `'en'`, `'ja'`）。 |
| `region` | `string` | - | 区域偏向（例如 `'US'`, `'JP'`）。 |
| `v` | `string` | - | API 版本：`'weekly'`、`'quarterly'`、`'beta'` 或 `'alpha'`。默认省略（Google 默认为 `'weekly'`）。 |

## 返回值

| 属性 | 类型 | 描述 |
|----------|------|-------------|
| `onLoaded` | `(fn) => void` | SDK 就绪时的回调。接收 Google Maps API 实例。 |
| `load` | `() => Promise` | 手动触发脚本加载。 |
| `status` | `Ref<string>`{lang="html"} | 当前加载状态（`'awaitingLoad'`、`'loading'`、`'loaded'`、`'error'`）。 |

## 示例

### 基础地图

加载 Google Maps SDK 并以编程方式创建地图。

```vue
<script setup lang="ts">
/// <reference types="google.maps" />
const { onLoaded } = useScriptGoogleMaps({
  apiKey: 'key',
})
const mapEl = ref()
onMounted(() => {
  onLoaded(async (instance) => {
    const maps = await instance.maps
    new maps.Map(mapEl.value, {
      center: { lat: -34.397, lng: 150.644 },
      zoom: 8,
    })
  })
})
</script>

<template>
  <div ref="mapEl" style="width: 100%; height: 400px;" />
</template>
```

### 地理编码

使用此组合式函数访问地理编码器 API。

```vue
<script setup lang="ts">
const { onLoaded } = useScriptGoogleMaps({
  apiKey: 'key',
  libraries: ['geocoding'],
})

async function geocodeAddress(address: string) {
  onLoaded(async (instance) => {
    const maps = await instance.maps
    const geocoder = new maps.Geocoder()
    const result = await geocoder.geocode({ address })
    console.log(result.results[0]?.geometry.location.toJSON())
  })
}
</script>
```

### 导入额外库

在运行时加载额外的库（例如 Places、Drawing）。

```vue
<script setup lang="ts">
const { onLoaded } = useScriptGoogleMaps({
  apiKey: 'key',
})

onMounted(() => {
  onLoaded(async (instance) => {
    const maps = await instance.maps
    const places = await maps.importLibrary('places')
    // 使用 places API
  })
})
</script>
```

::callout
在大多数情况下，优先使用 [`<ScriptGoogleMaps>`{lang="html"}](/scripts/google-maps/api/script-google-maps) 组件。它处理懒加载、占位图片，并提供声明式 API。当您需要直接访问 SDK 或构建自定义集成时，请使用 `useScriptGoogleMaps()`{lang="ts"}。
::
