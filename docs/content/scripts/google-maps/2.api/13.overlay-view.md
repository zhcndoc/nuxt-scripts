---
title: <ScriptGoogleMapsOverlayView>
---

在地图的经纬度位置上渲染任意 Vue 插槽内容。与 `InfoWindow` 不同，你可以完全控制 HTML 结构和样式。

::script-types{script-key="google-maps" filter="ScriptGoogleMapsOverlayView"}
::

## 标记锚定

当嵌套在 `ScriptGoogleMapsMarker` 或 `ScriptGoogleMapsAdvancedMarkerElement` 内部时，该遮罩层会自动继承标记的位置。这使其成为 `InfoWindow` 的完全可定制替代方案，并且当标记被拖动时，遮罩层会跟随标记移动。

```vue
<template>
  <ScriptGoogleMaps api-key="你的API密钥">
    <ScriptGoogleMapsAdvancedMarkerElement
      :position="{ lat: -34.397, lng: 150.644 }"
      :options="{ gmpDraggable: true }"
    >
      <ScriptGoogleMapsOverlayView
        anchor="bottom-center"
        :offset="{ x: 0, y: -50 }"
      >
        <div class="custom-tooltip">
          完全自定义内容，不受 InfoWindow 限制
        </div>
      </ScriptGoogleMapsOverlayView>
    </ScriptGoogleMapsAdvancedMarkerElement>
  </ScriptGoogleMaps>
</template>
```

## 点击标记时弹出

使用 `v-model:open` 可以保持遮罩层挂载，通过 CSS 切换可见性。这避免了重新挂载的开销并保留内部状态。

```vue
<script setup lang="ts">
const open = ref(false)
</script>

<template>
  <ScriptGoogleMaps api-key="你的API密钥">
    <ScriptGoogleMapsAdvancedMarkerElement
      :position="{ lat: -34.397, lng: 150.644 }"
      @click="open = !open"
    >
      <ScriptGoogleMapsOverlayView
        v-model:open="open"
        anchor="bottom-center"
        :offset="{ x: 0, y: -50 }"
      >
        <div class="custom-popup">
          <button @click.stop="open = false">
            ×
          </button>
          <p>此处可放置任何 Vue 内容</p>
        </div>
      </ScriptGoogleMapsOverlayView>
    </ScriptGoogleMapsAdvancedMarkerElement>
  </ScriptGoogleMaps>
</template>
```

对于重新挂载可接受的简单场景，也可以使用 `v-if`：

```vue
<ScriptGoogleMapsAdvancedMarkerElement
  :position="{ lat: -34.397, lng: 150.644 }"
  @click="open = true"
>
  <ScriptGoogleMapsOverlayView v-if="open">
    <MyPopup @close="open = false" />
  </ScriptGoogleMapsOverlayView>
</ScriptGoogleMapsAdvancedMarkerElement>
```

## 持久标签

```vue
<template>
  <ScriptGoogleMaps api-key="你的API密钥">
    <ScriptGoogleMapsOverlayView
      :position="{ lat: -34.397, lng: 150.644 }"
      anchor="center"
      :block-map-interaction="false"
    >
      <span class="bg-white px-1.5 py-0.5 rounded">
        标签文本
      </span>
    </ScriptGoogleMapsOverlayView>
  </ScriptGoogleMaps>
</template>
```

## 地图平移

当遮罩层打开时，地图会自动平移以确保遮罩层完全可见，这与原生 `InfoWindow` 的行为一致。默认边距为距离地图边缘 40px。

要自定义边距或禁用平移：

```vue
<!-- 自定义边距 -->
<ScriptGoogleMapsOverlayView :pan-on-open="60">
  ...
</ScriptGoogleMapsOverlayView>

<!-- 禁用平移 -->
<ScriptGoogleMapsOverlayView :pan-on-open="false">
  ...
</ScriptGoogleMapsOverlayView>
```

## 集群感知

当在 `ScriptGoogleMapsMarkerClusterer` 内部使用时，当其父标记在缩小视图时加入集群，遮罩层视图会自动隐藏。这可以防止孤立的遮罩层漂浮在集群图标上方。

当其标记被集群时，遮罩层会将 `v-model:open` 更新为 `false`。用户在放大回来后需要重新打开遮罩层（例如再次点击标记）。

要禁用此行为：

```vue
<ScriptGoogleMapsMarkerClusterer>
  <ScriptGoogleMapsAdvancedMarkerElement :position="markerPosition">
    <ScriptGoogleMapsOverlayView :hide-when-clustered="false">
      ...
    </ScriptGoogleMapsOverlayView>
  </ScriptGoogleMapsAdvancedMarkerElement>
</ScriptGoogleMapsMarkerClusterer>
```

## 过渡动画

遮罩层会在其内容元素上设置 `data-state` 属性（`"open"` 或 `"closed"`），从而启用 CSS 过渡和动画来实现进入/离开效果。关闭时，组件会等待任何正在运行的 `transitionend` 或 `animationend` 事件完成后才会隐藏元素。

`data-state` 也可作为插槽属性用于条件样式设置。

### CSS 动画

```vue
<ScriptGoogleMapsOverlayView v-model:open="open">
  <template #default="{ dataState }">
    <div class="popup" :data-state="dataState">
      带动画的弹出层
    </div>
  </template>
</ScriptGoogleMapsOverlayView>

<style>
.popup[data-state="open"] {
  animation: fadeIn 200ms ease-out;
}
.popup[data-state="closed"] {
  animation: fadeOut 150ms ease-in;
}
@keyframes fadeIn {
  from { opacity: 0; transform: scale(0.95); }
  to { opacity: 1; transform: scale(1); }
}
@keyframes fadeOut {
  from { opacity: 1; transform: scale(1); }
  to { opacity: 0; transform: scale(0.95); }
}
</style>
```

### CSS 过渡

```vue
<ScriptGoogleMapsOverlayView v-model:open="open">
  <template #default="{ dataState }">
    <div
      class="popup"
      :style="{
        opacity: dataState === 'open' ? 1 : 0,
        transition: 'opacity 200ms ease',
      }"
    >
      淡入淡出过渡
    </div>
  </template>
</ScriptGoogleMapsOverlayView>
```

::callout
`blockMapInteraction` 属性（默认为 `true`）会调用 `google.maps.OverlayView.preventMapHitsAndGesturesFrom()`{lang="ts"}，以阻止点击、轻触和拖动事件从遮罩层传播到地图。对于标签等非交互式遮罩层，请将其设置为 `false`。
::
