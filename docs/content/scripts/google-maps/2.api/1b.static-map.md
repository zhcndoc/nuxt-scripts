---
title: <ScriptGoogleMapsStaticMap>
---

渲染一张 [Google Maps 静态 API](https://developers.google.com/maps/documentation/maps-static) 图片。单独使用用于静态地图预览，或放入 [`<ScriptGoogleMaps>`{lang="html"}](/scripts/google-maps/api/script-google-maps) 的 `#placeholder` 插槽中作为加载占位符。

::callout{type="info"}
当配置 `NUXT_SCRIPTS_PROXY_SECRET` 时，本脚本的代理端点使用 [HMAC URL 签名](/docs/guides/first-party#proxy-endpoint-security)。请参阅 [安全指南](/docs/guides/first-party#proxy-endpoint-security) 获取设置说明。
::

::script-types{script-key="google-maps" filter="ScriptGoogleMapsStaticMap"}
::

## 用法

### 独立使用

显示静态地图，无需加载交互式 Google Maps JavaScript API。

```vue
<template>
  <ScriptGoogleMapsStaticMap
    center="51.95,19.13"
    :zoom="7"
    width="100%"
    height="300"
  />
</template>
```

### 作为占位符

在 [`<ScriptGoogleMaps>`{lang="html"}](/scripts/google-maps/api/script-google-maps) 内部使用，以便在交互式地图加载时显示静态地图。

```vue
<template>
  <ScriptGoogleMaps
    :map-options="{
      center,
      zoom: 7,
    }"
  >
    <template #placeholder>
      <ScriptGoogleMapsStaticMap
        :center="center"
        :zoom="7"
        loading="eager"
        maptype="satellite"
      />
    </template>
  </ScriptGoogleMaps>
</template>
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `center` | `string \| { lat: number, lng: number }` | | 地图中心，格式为 `"lat,lng"` 字符串或 `LatLngLiteral`。 |
| `zoom` | `number` | `15` | 缩放级别（0 到 21）。 |
| `size` | `` `${number}x${number}` `` | auto | API 请求的明确像素大小。省略时，在挂载时测量渲染容器的尺寸。SSR 期间回退到 `640x400`。 |
| `scale` | `1 \| 2` | `2` | 设备像素比。 |
| `format` | `StaticMapFormat` | | 图片格式：`png`, `jpg`, `gif`, `png8`, `png32`, `jpg-baseline`。 |
| `maptype` | `StaticMapType` | | 地图类型：`roadmap`, `satellite`, `terrain`, `hybrid`。 |
| `mapId` | `string` | | 基于云的地图样式 ID。 |
| `markers` | `string \| string[]` | | [标记描述符](https://developers.google.com/maps/documentation/maps-static/start#Markers)。 |
| `path` | `string \| string[]` | | [折线路径描述符](https://developers.google.com/maps/documentation/maps-static/start#Paths)。 |
| `visible` | `string \| string[]` | | 地图上应可见的位置。 |
| `style` | `string \| string[] \| MapTypeStyle[]` | | 地图样式。接受原始 Static Maps API 样式字符串或 Google Maps JS API `MapTypeStyle[]` 对象。 |
| `language` | `string` | | 地图标签的语言代码。 |
| `region` | `string` | | 区域偏好。 |
| `signature` | `string` | | 无密钥请求的数字签名。 |
| `apiKey` | `string` | | API 密钥覆盖。优先级高于代理；省略时组件回退到服务器端密钥。 |
| `width` | `number \| string` | `640` | 容器的 CSS 宽度。 |
| `height` | `number \| string` | `400` | 容器的 CSS 高度。 |
| `loading` | `'eager' \| 'lazy'` | `'lazy'` | 图片加载策略。 |
| `objectFit` | `string` | `'cover'` | 容器内 `<img>`{lang="html"} 的 object-fit。 |
| `imgAttrs` | `ImgHTMLAttributes` | | `<img>`{lang="html"} 元素的附加属性。 |

## 尺寸处理

当未提供 `size` 时，组件：

1. **客户端**：在挂载时测量容器的像素尺寸，并限制在 [静态地图 API 限制](https://developers.google.com/maps/documentation/maps-static/start) 的 640x640 以内（保持纵横比）。
2. **SSR**：如果 `width`/`height` 属性都是像素值，则从中派生。
3. **回退**：使用 `640x400`。

明确设置 `size` 以绕过自动测量。

## 代理支持

在 `scripts.registry` 中配置 `googleMaps` 会自动启用服务器端代理。除非你提供明确的 `apiKey` 属性，否则组件将通过代理路由请求。

## 插槽

**default**

使用自定义模板覆盖 `<img>`{lang="html"} 元素。接收包含计算后的静态地图 URL 的 `{ src }`。

```vue
<template>
  <ScriptGoogleMapsStaticMap center="51.95,19.13" :zoom="7">
    <template #default="{ src }">
      <img :src="src" alt="Custom static map" class="rounded-lg shadow">
    </template>
  </ScriptGoogleMapsStaticMap>
</template>
```
