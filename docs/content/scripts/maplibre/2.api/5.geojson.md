---
title: <ScriptMapLibreGeoJson>
---

添加一个 GeoJSON 源和一个或多个 MapLibre 样式图层。替换 `data` 会更新现有源；更改图层或源选项会按受控顺序重建资源。

更改 `source-id` 会先移除之前由组件管理的源和图层，然后在新的 ID 下重新创建它们。

::script-types{script-key="maplibre" filter="ScriptMapLibreGeoJson"}
::

除非图层明确指定了其他源，否则每个图层都会使用组件的 `source-id`。地图样式发生变化后，组件也会恢复其源和图层。

远程获取数据有意不在组件内部处理。请使用 `useFetch` 获取并验证数据，然后将结果对象传递给 `data`，以便明确呈现加载和失败状态。
