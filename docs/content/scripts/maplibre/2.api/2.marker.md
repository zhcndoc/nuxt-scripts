---
title: <ScriptMapLibreMarker>
---

添加一个响应式的 MapLibre `Marker`。请提供唯一的 `aria-label`，以便其生成的 DOM 元素具有有用的可访问名称。

::script-types{script-key="maplibre" filter="ScriptMapLibreMarker"}
::

在默认插槽中嵌套一个 [`<ScriptMapLibrePopup>`{lang="html"}](/scripts/maplibre/api/popup)，即可将其绑定到标记。使用 `options.draggable` 和拖动事件来实现可编辑标记。

具有公开 setter 的标记选项会进行响应式更新，包括类名、拖动、旋转和俯仰对齐、偏移、不透明度以及亚像素定位。MapLibre 会在创建标记时读取仅可通过构造函数设置的选项，例如 `element`、`anchor`、`color` 和 `scale`。
